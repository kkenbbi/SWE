# Farmers Market App – Product Search & Filter Feature

This iOS application is centered around a **Farmers Market platform**, enabling users to explore a variety of fresh, local produce. It provides an intuitive and interactive way to **search products by name** and **filter them by price**. The project is built using **Swift and UIKit**.

## 🔍 Feature: Search & Filter

My contribution to the project focused on the **search and filtering component** of the app:

- **SearchBar Integration**: Implemented a dynamic search feature allowing users to search products by name in real-time.
- **Price Filter View**: Created a user interface for users to enter minimum and maximum price ranges.
- **Live Filtering Logic**: Developed the filtering logic that works in combination with search queries to return relevant results based on name and price range.

## 🛒 About the App

While my work focused on the search feature, the app as a whole is designed to:

- List products from local farmers and vendors
- Enable browsing by categories (e.g., fruits, vegetables, dairy)
- Allow users to view product details, prices, and freshness information
- Provide filtering and sorting options based on user preferences

## 🛠 Technologies Used

- **Swift**
- **UIKit**
- **MVVM Architecture**
- **Programmatic UI using Auto Layout**
